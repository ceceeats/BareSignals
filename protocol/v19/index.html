Step four

Keep it and come back to it

The page address always holds the latest version. Save it once and it opens exactly like this, ready to edit.

  • On a phone: open the link, then Share → Add to Home Screen (iPhone) or ⋮ → Add to home screen (Android). It opens like an app.
  • On a laptop: bookmark the page. The address updates every time you save, so the bookmark is the newest version once you re-bookmark after edits.
  • Edit later: open the link, change anything, save. Then copy or send the new link: the old link still opens the old version.
  • Google Calendar or Apple Calendar: Add to my calendar downloads a calendar file with every dose at her own times for the next 4 months, plus restock days and blood tests. iPhone: open the file, Add All. Google: calendar.google.com → Settings → Import, pick the file. Make a new calendar for it first, so it can be removed in one go when the protocol changes.
  • With an AI: Copy for my AI gives a plain list. Ask ChatGPT or Claude to change it, then paste its answer into Paste it back.
