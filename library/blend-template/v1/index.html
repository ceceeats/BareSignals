Blend Template v1: what each block does

  1. Header: name, "Blend · N peptides", the one-line use, total mg box (like the AA box on single cards).
  2. Ratio bar + components: mg share drawn to scale in each component's main role colour. Every row opens that compound's own card.
  3. Typical dose: blend-level where reports exist; otherwise "No standard dose", plus a per-draw table showing what each component works out to. Calculator gets a blend mode later.
  4. Stripe + What it's for: all the components' roles merged. Until blend-specific reports exist, widths follow mg share × each component's role order. A role only one component brings is labelled with it.
  5. Why combined: what each part covers that the others don't.
  6. Mixing chemistry: the shared "made in the factory" explainer, plus this blend's own watch points.
  7. Blood work + supplements: merged automatically from each component's entry, deduplicated, tagged with which component asks for it.
  8. People report, versions, timeline, sources: same as single cards. "Versions" lists the ratios on the market and on her stickers.

Library gets a Blends filter and blend tiles marked "BLEND" instead of an AA count. Single cards gain an "In blends" line linking back here.
